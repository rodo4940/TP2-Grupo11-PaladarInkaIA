# AGENTS.md

## Arquitectura

- Monolito modular.
- Backend FastAPI.
- Frontend React.
- PostgreSQL como fuente de verdad operativa.
- Docker y Docker Compose para ejecucion local reproducible.

## Reglas

- No convertir el proyecto en microservicios.
- No cambiar tecnologias sin autorizacion.
- No introducir dependencias innecesarias.
- No modificar modulos fuera del alcance de la tarea.
- No implementar funcionalidades futuras anticipadamente.
- No introducir secretos.
- Ejecutar pruebas antes de finalizar.
- Mantener reglas de negocio en backend.
- Preservar migraciones.
- Evitar codigo duplicado.
- Actualizar README si cambia el procedimiento de instalacion.

## IA

Todavia no implementar OpenAI, RAG o Machine Learning. Eso pertenece a tareas posteriores.
