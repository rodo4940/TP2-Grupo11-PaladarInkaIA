# Contribucion

## Reglas Git

Despues del bootstrap inicial, esta prohibido realizar push directo a `main`.

Cada cambio funcional debe ingresar mediante Pull Request. El autor no debe aprobar como unica revision su propio Pull Request.

## Ramas

- `feature/`
- `fix/`
- `test/`
- `docs/`
- `refactor/`
- `chore/`

## Commits

Usar el formato:

- `feat(scope): descripcion`
- `fix(scope): descripcion`
- `test(scope): descripcion`
- `docs(scope): descripcion`
- `refactor(scope): descripcion`
- `chore(scope): descripcion`

## Antes de enviar cambios

- Ejecutar pruebas relevantes.
- No incluir secretos.
- Actualizar documentacion cuando cambie el procedimiento de instalacion o ejecucion.
